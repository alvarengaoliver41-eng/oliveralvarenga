# oliveralvarenga.com

Sitio estático: `index.html` + `assets/money.jpg`.

La página es un efecto animado en canvas (dither verde, estilo "All about the Benjamins" de 21st.dev) sobre una foto de billetes de 100 dólares. Los parámetros del efecto están en el objeto `P` dentro de `index.html`.

Deploy en Vercel sin framework ni build command.
